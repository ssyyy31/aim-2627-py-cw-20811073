## Prompt
这道题要求实现 `next_step_toward(pos, target, obstacles, current_facing=Facing.UP)`：
- 目标是让机器人从当前位置走向目标点，且每步尽量缩短到目标的 Manhattan 距离；
- 优先考虑大轴差值（横向或纵向优先），避免直接走错方向；
- 若当前方向不可用或会撞墙，就回退到其他合法候选方向；
- 若没有任何候选能缩短距离，返回当前朝向以保持稳定。

我给 AI 的提示大意是：补一个“向目标前进一格”的启发式函数，结合障碍和大轴优先策略，确保机器人只走更好的方向而不是随机转动。

## AI 初始代码
```python
def next_step_toward(pos, target, obstacles, current_facing=Facing.UP):
    """返回使目标更接近的下一步朝向；若没有合适候选则返回当前朝向。"""
    x, y = pos
    tx, ty = target
    obstacles = set(obstacles)

    def step_for(facing):
        dx, dy = facing.delta
        return (x + dx, y + dy)

    def can_move(facing):
        nx, ny = step_for(facing)
        if (nx, ny) in obstacles:
            return False
        return True

    # 优先考虑更大轴差值；若该轴方向不可用，则退回另一个轴
    dx = abs(tx - x)
    dy = abs(ty - y)

    candidates = []
    if dx >= dy:
        if tx > x:
            candidates.append(Facing.RIGHT)
        elif tx < x:
            candidates.append(Facing.LEFT)
        if ty > y:
            candidates.append(Facing.UP)
        elif ty < y:
            candidates.append(Facing.DOWN)
    else:
        if ty > y:
            candidates.append(Facing.UP)
        elif ty < y:
            candidates.append(Facing.DOWN)
        if tx > x:
            candidates.append(Facing.RIGHT)
        elif tx < x:
            candidates.append(Facing.LEFT)

    # 先选使曼哈顿距离缩短的方向；没有则退回 current_facing
    for facing in candidates:
        if not can_move(facing):
            continue
        nx, ny = step_for(facing)
        before = abs(x - tx) + abs(y - ty)
        after = abs(nx - tx) + abs(ny - ty)
        if after < before:
            return facing

    return current_facing
```

## My modifications
- 按横向/纵向差值大小决定优先方向，保证棋盘导航优先走更重要的轴；
- 先检查候选方向是否可走（不在障碍上），避免“向墙走”或撞到障碍；
- 对每个候选计算 `before` 和 `after` 的 Manhattan 距离，只有在确实更近时才返回该方向；
- 若所有候选都不更优，则退回 `current_facing`，保证函数在极端情况下不会报错或返回错误方向；
- 对于障碍较多的情况，策略回落到可行方向而不是死循环。
