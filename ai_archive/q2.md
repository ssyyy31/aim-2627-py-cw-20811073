## Prompt
这道题要求实现 `analyze_damage_log(lines)`：
- 解析混合格式的伤害日志，包括 JSON 一行和传感器字符串形式；
- 需要合并统计各部位伤害（front/left/right）；
- 需要计算总伤害、平均伤害和 `most_hit` 部位；
- 日志中可能含有重复 `id`、空行、注释、非数字、负数、无效键等异常数据；
- 最终结果必须稳定并符合测试的字段规范。

我给 AI 的提示大意是：实现一个兼容 JSON 和 `F:32,L:5,R:12` 这种混合输入的解析器，并过滤无效数据，确保 `total`、`by_armor`、`most_hit`、`avg` 正确。

## AI 初始代码
```python
def analyze_damage_log(lines):
    """解析混合格式伤害日志，返回总量、按部位统计、最重部位和平均值。"""
    by_armor = {"front": 0, "left": 0, "right": 0}
    total = 0
    seen_ids = set()
    valid_count = 0

    for raw in lines or []:
        if raw is None:
            continue

        line = str(raw).strip()
        if not line or line.startswith("#"):
            continue

        # JSON 形式：{"armor": "front", "damage": 30, "id": 7}
        if line.startswith("{"):
            try:
                obj = json.loads(line)
            except json.JSONDecodeError:
                continue
            if not isinstance(obj, dict):
                continue

            armor = obj.get("armor")
            damage = obj.get("damage")
            if armor not in by_armor:
                continue

            if "id" in obj:
                obj_id = obj["id"]
                if obj_id in seen_ids:
                    continue
                seen_ids.add(obj_id)

            if isinstance(damage, bool):
                continue
            if isinstance(damage, int):
                dmg = damage
            elif isinstance(damage, float) and damage.is_integer():
                dmg = int(damage)
            else:
                try:
                    dmg = int(damage)
                except (TypeError, ValueError):
                    continue

            if dmg < 0:
                continue

            by_armor[armor] += dmg
            total += dmg
            valid_count += 1
            continue

        # 传感器行：F:32,L:5,R:12
        entries = [part.strip() for part in line.split(",")]
        if not entries:
            continue

        valid_pairs = []
        for part in entries:
            if not part or ":" not in part:
                valid_pairs = None
                break
            left, right = part.split(":", 1)
            key = left.strip().upper()
            value = right.strip()
            if key not in {"F", "L", "R"}:
                valid_pairs = None
                break
            try:
                dmg = int(value)
            except ValueError:
                valid_pairs = None
                break
            if dmg < 0:
                valid_pairs = None
                break
            valid_pairs.append((key, dmg))

        if valid_pairs is None:
            continue

        for key, dmg in valid_pairs:
            armor_key = {"F": "front", "L": "left", "R": "right"}[key]
            by_armor[armor_key] += dmg
            total += dmg
            valid_count += 1

    if valid_count == 0:
        most_hit = None
        avg = 0.0
    else:
        max_damage = max(by_armor.values())
        most_hit = next(armor for armor in ("front", "left", "right")
                        if by_armor[armor] == max_damage)
        avg = total / valid_count

    return {
        "total": total,
        "by_armor": by_armor,
        "most_hit": most_hit,
        "avg": float(avg),
    }
```

## My modifications
- 支持两种日志格式的混合输入：JSON 一行和 `F/L/R:damage` 形式；
- 对重复 `id` 做去重处理，避免同一条记录重复计数；
- 对无效行、空行、注释、非法数字、负数、布尔值和不合法部位做过滤；
- `most_hit` 通过 `max(by_armor.values())` 选出最大伤害部位，并在全空数据时返回 `None`；
- `avg` 按有效样本数 `valid_count` 计算，避免被空值或非法输入污染；
- 对 `by_armor` 的统计顺序稳定，保证测试结果可复现。
