## Prompt
这道题要求实现巡逻主循环 `run_patrol(grid, max_steps=500)` 和 JSON 汇总 `report_to_json(stats)`：
- 需要在地图中沿着敌人方向推进，直到找到敌人或者步数超出上限、无燃料或中断；
- 需要统计 `steps`、`collisions`、`visited_count`、`found_enemy`、`success`；
- `report_to_json` 必须输出固定顺序的 JSON，保证测试可比较；
- 需要兼顾障碍绕开、卡死处理和边界安全。

我给ai的基础大意是根据 `next_step_toward` 的结果控制巡逻移动，并把统计结果以稳定顺序输出，确保测试的 JSON 比较一致。

## AI 初始代码
```python
def run_patrol(grid, max_steps=500):
    """巡逻主循环：沿着敌方目标前进，直到找到敌人或超时/断电。"""
    if max_steps < 0:
        max_steps = 0

    visited = {grid.current_pos}
    found_enemy = grid.found_enemy
    steps = 0

    while steps < max_steps and not found_enemy and grid.fuel > 0:
        target = grid.enemy_pos
        desired = next_step_toward(grid.current_pos, target, grid.obstacles,
                                   grid.facing)

        if desired is not grid.facing:
            order = [Facing.UP, Facing.RIGHT, Facing.DOWN, Facing.LEFT]
            curr_idx = order.index(grid.facing)
            dest_idx = order.index(desired)
            diff = (dest_idx - curr_idx) % 4
            if diff == 1:
                grid.turn_right()
            elif diff == 2:
                grid.turn_right()
                grid.turn_right()
            elif diff == 3:
                grid.turn_left()

        before = grid.current_pos
        grid.move_forward()
        visited.add(grid.current_pos)
        steps += 1
        found_enemy = grid.found_enemy

        if grid.current_pos == before and not found_enemy:
            # 若前方被挡，继续按当前方向再试一次，避免卡死；
            # 这样在多障碍地图上仍可推进到可行路径。
            desired = next_step_toward(grid.current_pos, target, grid.obstacles,
                                       grid.facing)
            if desired is not grid.facing:
                order = [Facing.UP, Facing.RIGHT, Facing.DOWN, Facing.LEFT]
                curr_idx = order.index(grid.facing)
                dest_idx = order.index(desired)
                diff = (dest_idx - curr_idx) % 4
                if diff == 1:
                    grid.turn_right()
                elif diff == 2:
                    grid.turn_right()
                    grid.turn_right()
                elif diff == 3:
                    grid.turn_left()

        if grid.current_pos == target:
            found_enemy = True
            break

    stats = {
        "steps": steps,
        "collisions": int(grid.collision_count),
        "visited_count": len(visited),
        "found_enemy": bool(found_enemy),
        "success": bool(found_enemy),
    }
    return stats


def report_to_json(stats):
    """以固定顺序序列化巡逻统计，确保 JSON 输出稳定且可比较。"""
    ordered = {
        "steps": int(stats.get("steps", 0)),
        "collisions": int(stats.get("collisions", 0)),
        "visited_count": int(stats.get("visited_count", 0)),
        "found_enemy": bool(stats.get("found_enemy", False)),
        "success": bool(stats.get("success", False)),
    }
    return json.dumps(ordered)
```

## My modifications
- 让巡逻循环依赖 `next_step_toward` 计算目标方向，然后通过最短旋转路径转向；
- 在每步前进后记录 `visited`，用以统计访问格子数量；
- 若前方被挡且没找到敌人，则触发额外处理以避免卡死；
- 统计中明确保留 `steps`、`collisions`、`visited_count`、`found_enemy` 和 `success`；
- `report_to_json` 固定字段顺序，保证 JSON 在字符串层面稳定，便于测试比较；
- 处理 `max_steps < 0` 时直接归零，避免无效负值造成逻辑异常。
